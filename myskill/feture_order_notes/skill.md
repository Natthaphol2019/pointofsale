# Skill: Add Note to Order Items
**Role:** Staff
**Page:** `/order/[id]/page.tsx`
ห้ามลบหรือแก้ไขโค้ดในไฟล์ `app/page.tsx` และ `app/(admin)/layout.tsx` ที่เกี่ยวข้องกับการเชื่อมต่อ Supabase โดยเด็ดขาด เพื่อป้องกันการเกิดข้อผิดพลาดในการทำงานของระบบ ให้ถามก่อน ถ้าไม่ชัวร์ว่าต้องแก้ไขส่วนไหนบ้างให้ถามก่อนนะครับ
## 🎯 เป้าหมาย (Objective)
พนักงานสามารถพิมพ์ "หมายเหตุ (Note)" กำกับรายการอาหารแต่ละจานในตะกร้าได้โดยตรง (Inline Input) เพื่อระบุความต้องการพิเศษของลูกค้า โดยไม่ต้องเปิดหน้าต่างใหม่ และไม่ต้องมี Kitchen Screen แยก (Single Workflow)

## 🛠️ วิธีการทำงาน (Implementation Details)
1. เพิ่มฟังก์ชัน `handleUpdateNote` เพื่อทำการอัปเดตคอลัมน์ `note` ในตาราง `order_items`
2. แทรก `<input type="text" />` ไว้ใต้ชื่อเมนูแต่ละรายการในตะกร้าฝั่งขวามือ
3. ใช้ Event `onBlur` ในการ Trigger ฟังก์ชันอัปเดตฐานข้อมูล (หลีกเลี่ยงการใช้ `onChange` ตรงๆ เพื่อป้องกันการยิง API รัวเกินไปขณะพิมพ์)
